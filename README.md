# 📂 Folder & File Analyzer

![demo screenshot.png](https://files.catbox.moe/v82cxz.png)

A lightweight, client-side web tool to analyze directory structures and count files/folders directly in your browser.

## ✨ Features

- **100% Client-Side** - No server processing, your files never leave your computer
- **Drag & Drop** - Intuitive folder selection
- **Real-Time Counting** - Animated counters show file/folder totals
- **Persistent Likes** - Like your favorite folders (stored in localStorage)
- **Responsive Design** - Works on desktop and mobile devices
- **Zero Installation** - Runs in any modern browser

## 🚀 Usage

1. **Open** `https://mehmain.github.io/File-Folders-Analyzer/` in any modern browser (Chrome/Firefox/Edge recommended)
2. **Select** a folder using:
   - Click the upload area
   - Or drag & drop a folder (Chrome/Edge only)
3. **View** the analysis results including:
   - Total file count
   - Total folder count
   - Analysis timestamp
4. **Like** ❤️ your favorite folders (persists between sessions)
